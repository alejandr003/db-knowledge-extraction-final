## 4. Link hygiene rules

1. Use the canonical repository URL, not a fork.
2. Prefer GitHub `blob` links for files:
   `https://github.com/<user>/<repo>/blob/main/<path>`
3. Do not share temporary upload links or links that expire.
4. Re-test every link **after** the last commit; a push can change nothing, but a renamed
   file breaks the link.
5. Keep this file updated whenever a link changes.
